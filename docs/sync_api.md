Sync API (minimal)

Endpoints

- GET /sync/version
  - Returns latest content version, e.g. {"version":"2025-10-24T09:00:00Z"}

- GET /sync/snapshot
  - Returns a JSON snapshot with all content tables. Example shape:
  {
    "version": "2025-10-24T09:00:00Z",
    "categories": [{"id":1,"name":"UK","order":0,"pass_percent":60,"image_url":"","locked":false}],
    "subcategories": [{"id":1,"category_id":1,"name":"History","order":0,"image_url":"","locked":false}],
    "exams": [{"id":1,"title":"Test 1","description":"","category_id":1,"subcategory_id":1,"question_count":50,"published":true,"time_limit_minutes":0,"shuffle_options":true,"negative_marking":false,"pass_percent":60,"theme_key":0}],
    "questions": [{"id":10,"body":"When...","explanation":"","multiple":false,"locked":false}],
    "choices": [{"id":101,"question_id":10,"label":"1666","is_correct":true,"order":0}],
    "exam_questions": [{"id":1,"exam_id":1,"question_id":10,"order":0,"points":1}],
    "exam_grade_bands": [{"id":1,"exam_id":1,"min_percent":60,"label":"Pass","color":"#4CAF50"}]
  }

Notes
- Field names are snake_case matching the SQLite schema columns generated by Drift.
- Apps compare /sync/version to local app_settings.content_version and prompt users to update when different.

Import rules (client)
- Deletes and replaces content tables (categories, subcategories, exams, questions, choices, exam_questions, exam_grade_bands, links) in a transaction.
- Does NOT delete attempts, attempt_answers, saved_questions, users.
- Stores content_version after import.
